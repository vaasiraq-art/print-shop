# Print Shop

تطبيق Windows لإدارة طباعة ملفات PDF المتعددة بنظام تبويبات (زي المتصفح)، مبني بـ Electron.

## المميزات
- فتح PDF بالسحب والإفلات أو بمسار الجهاز
- تبويبات متعددة، كل تبويب يشتغل بطابعة مختلفة (من كل الطابعات المتصلة بالجهاز)
- طباعة تبويب واحد أو "طباعة الكل" بضغطة وحدة
- عداد إجمالي الصفحات لكل التبويبات المفتوحة
- Presets محفوظة لإعدادات الطباعة المتكررة
- سجل طباعة (تاريخ، اسم الملف، الطابعة، عدد الصفحات)
- تحذير قبل طباعة ملف كبير (50+ صفحة)
- اختصارات: Ctrl+O فتح، Ctrl+P طباعة التبويب النشط، Ctrl+Shift+P طباعة الكل، Ctrl+W إغلاق تبويب

## التشغيل (وضع التطوير)

يحتاج جهازك Node.js مثبت (نزّله من nodejs.org إذا ما عندك).

```bash
cd print-shop-app
npm install
npm start
```

## بناء ملف تثبيت Windows (.exe)

```bash
npm run dist
```

الملف النهائي رح يطلع بمجلد `dist/` — ملف `.exe` تقدر تنزله وتوزعه على أي جهاز Windows 11 بدون ما يحتاج Node مثبت.

## ملاحظات
- التطبيق يستخدم عارض PDF الأصلي بتاع Chromium (نفس شكل Chrome بالضبط) عبر `BrowserView` مع تفعيل `plugins: true`.
- قائمة الطابعات تُسحب مباشرة من نظام Windows عبر `webContents.getPrintersAsync()` — تعرض كل الطابعات المتصلة بدون أي تحديد.
- الإعدادات المحفوظة (presets) وسجل الطباعة يتخزنون محلياً بجهازك عبر `electron-store` (ملف JSON بمجلد AppData).
